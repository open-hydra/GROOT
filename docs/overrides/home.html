Everything you need for radiative heat transfer

A complete, battle-tested radiation solver written in modern Fortran

Discrete Transfer Method

Solves the steady-state radiative transfer equation via DTM on multi-block structured grids, providing both radiative heat flux and source term.

1D / 2D / 3D Geometries

Handles one-, two-, and three-dimensional configurations with periodic boundary conditions, enabling a wide range of test cases and coupled simulations.

Spectral Gas Models

Built-in support for gray gas and Weighted-Sum-of-Gray-Gases (WSGG) spectral models to account for wavelength-dependent emission and absorption.

OpenMP Parallelism

Shared-memory parallelism via OpenMP for efficient multi-core execution, enabling large-scale radiative calculations on workstations and HPC nodes.

Solver Coupling

Designed to be coupled with other Hydra suite solvers, providing the radiative heat flux and source term to CFD simulations of reacting flows.

Flexible I/O

Solution output in Tecplot (ASCII & binary) and VTK formats.

Up and running in minutes

GROOT ships with a single install script that handles all dependencies, compiles the Fortran core, and puts the binary on your PATH.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/GROOT.git
$ cd GROOT && ./install.sh

# Run a simulation
$ ./bin/GROOT
