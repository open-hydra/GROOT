# Input Format

GROOT is configured through a single **INI-format** file called `input.ini`, located in the case root directory.

The file is organized into parameter blocks — each block controls a specific aspect of the simulation (..). Parameters that are not specified take their default values.

```ini
[GROOT-Parameters]



```
